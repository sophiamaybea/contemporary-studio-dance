# Reference Corpus 001

This corpus represents the user's contemporary-dance taste from the first nine supplied reference clips.

The original videos stay private/local and are intentionally excluded from Git.

## Recurrent movement language

The corpus combines:

### FLOAT
Suspension, very long extensions, off-axis balance, curved pathways and delayed arrival.

### FRACTURE
Interrupted phrases, contractions, crooked limbs, abrupt redirection and deliberate non-pretty shapes.

### RELEASE
Falling, folding, floor contact, rebound and recovery through momentum.

### TRAVEL
Spirals, diagonals, walking mutations, changing facing and sustained locomotion.

## Strongest shared rule

A movement should have a **physical cause**.

Preferred:
`spiral -> loss of balance -> catch step -> rotation -> release -> rebound`

Discouraged:
`pose -> reset -> trick -> reset -> pose`

The target includes technical virtuosity, but technical movement should be embedded inside transition logic rather than displayed as a detached trick.
