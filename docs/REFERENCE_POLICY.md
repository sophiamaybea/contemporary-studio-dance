# Reference corpus policy

Reference videos may be copyrighted and should remain private/local unless there is explicit permission to redistribute them.

The repository stores:
- provenance metadata
- timestamps and annotations
- derived numeric measurements
- abstract movement descriptors
- learned movement grammar

It does **not** need to store the source videos themselves.

The design goal is original choreography informed by high-level movement properties, not frame-for-frame reconstruction of a choreographer's work.
