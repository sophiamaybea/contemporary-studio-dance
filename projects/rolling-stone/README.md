# Rolling Stone

Source-faithful transcription project.

Authoritative dance reference:
https://www.youtube.com/watch?v=0zGSE1ai8iM

This project is **not** an "inspired by" generation. The source choreography is treated as the motion target. The system recovers the dance into 3D, refines temporal dynamics, mathematically checks fidelity and only permits generative repair for low-confidence/occluded frames.
