# If There's Such a Thing as Love

A solo contemporary-dance project for **The Magnetic Fields' 2004 recording**.

## Core choreographic question

The body repeatedly tests whether a physical proposition can become stable.

The dance is built from:

```text
approach -> hesitation -> temporary conviction -> contradiction -> re-route
```

rather than from literal lyric interpretation.

## Mathematical idea

The project adds a deliberately paradoxical state:

```text
Q(t) = attraction(t) * avoidance(t)
```

High `Q(t)` means the dancer is strongly drawn toward something while
simultaneously organising the body to avoid arrival.

A recurring stage point `p*` acts as a spatial attractor. The dancer curves
around it repeatedly:

```text
r(t) = ||c_xy(t) - p*||
```

The choreography rewards **near-arrival** more than arrival until the
temporary-proof section.
